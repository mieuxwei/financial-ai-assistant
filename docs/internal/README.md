# Internal Development Archive

This directory preserves historical milestone plans, implementation handoffs and safety freezes
that remain useful for provenance but are not part of the primary portfolio narrative.

| file | classification | reason retained |
|---|---|---|
| `development_history.md` | INTERNAL_HISTORY | chronological implementation and deployment provenance |
| `project_plan_archive.md` | INTERNAL_HISTORY | frozen record of research-question and milestone evolution |
| `live_demo_product_audit.md` | INTERNAL_HISTORY | before/after product-review evidence |
| `r0_project_rebaseline_protocol.md` | RESEARCH_EVIDENCE | records the rebaseline and claim-boundary decisions |
| `gas_migration_safety_freeze.md` | SECURITY_EVIDENCE | records separation from the private legacy system |

These files intentionally retain historical milestone identifiers and workflow language where it
is necessary to explain chronology. They are archived instead of rewritten as if the development
process never occurred. Current status, claims and usage instructions are authoritative in the
root `README.md` and `docs/final_release_audit.md`.
